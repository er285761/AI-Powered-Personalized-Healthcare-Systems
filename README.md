# Personalised Healthcare Recommendation System

A research/educational prototype built around the supplied **Personalised Healthcare Recommendations Dataset** (2,000 synthetic patient records, 40 fields).

## What the system does

1. Accepts a synthetic patient from the dataset or a manually entered profile.
2. Engineers blood-pressure features from the `Blood_Pressure` field.
3. Uses three Random Forest classifiers to estimate:
   - Heart Disease Risk
   - Diabetes Risk
   - Overall Health Risk
4. Shows class probabilities so the result is not presented as absolute certainty.
5. Generates transparent, rule-based personalised recommendations for:
   - smoking
   - exercise
   - nutrition/weight-supportive habits
   - blood glucose
   - cardiovascular/lipid health
   - blood pressure
   - alcohol
   - sleep
   - mental wellbeing/social support
   - clinical follow-up prompts
6. Displays the factors and reasons behind recommendations.

## Important design choice

The ML models predict risk categories; they do **not** directly generate medical treatment. Recommendations are generated by explicit rules so users can inspect why a recommendation was produced. This is safer and easier to audit for a synthetic healthcare prototype.

## Run locally

### 1. Create environment

Windows:
```bash
python -m venv .venv
.venv\\Scripts\\activate
```

Linux/macOS:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Train the models

```bash
python train.py
```

This creates three model files under `models/` and prints hold-out accuracy and weighted F1.

### 4. Start the application

```bash
streamlit run app.py
```

The browser will open the dashboard.

## Model evaluation on the supplied dataset

With the included training configuration and a stratified 80/20 hold-out split, the baseline Random Forest models achieved approximately:

| Target | Accuracy | Weighted F1 |
|---|---:|---:|
| Heart Disease Risk | 79.3% | 77.5% |
| Diabetes Risk | 91.5% | 90.7% |
| Overall Health Risk | 78.0% | 77.0% |

These numbers are **not clinical performance claims**. The dataset is synthetic, and a random hold-out from the same generated population does not establish real-world medical validity.

## Recommended next development steps

- Add cross-validation and calibration of predicted probabilities.
- Add SHAP/permutation feature importance for explainability.
- Add a recommendation history database for longitudinal patient tracking.
- Add authentication and role-based access for patient/clinician/admin users.
- Add PostgreSQL for production persistence.
- Add a clinician review workflow before any recommendation is surfaced to a patient.
- Add audit logs and consent/privacy controls.
- Add unit tests and automated model-quality checks.
- Validate any future clinical version against real, appropriately governed clinical data.

## Safety

This project is a synthetic-data research prototype. It must not be used to diagnose patients, prescribe medication, replace clinical judgement, or make high-stakes healthcare decisions without appropriate clinical validation, governance, privacy controls, and professional oversight.
